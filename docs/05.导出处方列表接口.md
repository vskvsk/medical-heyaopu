
简要描述
- 获取处方列表数据（支持多条件查询）

请求URL
- /htai/prescribe/download

请求方式
- POST，body

请求头
- 参考接口必读中的请求头设置

请求参数
字段名
字段类型
是否必填
描述
pk_prescribe
string

1、仅支持精确查询，不能模糊查找
2、支持多单据号查询以英文格式的逗号进行单据号的分割
vbillcode
string

和药铺订单号模糊查询
isNuclearSide

string

核方状态查询
false：待核方
true：已标注
isSign

string

标注状态查询
false：待核方
true：已标注
doctor
string

开方医生模糊查询
patient
string

开方患者模糊查询
cellphone
string

患者电话
created_start
string

开单起始时间
created_end
string

开单结束时间
paymentd_start
string

付款起始时间
paymentd_end
string

付款截止时间
page
int
是
默认 1
rows
int
是
默认 5000
请求示例
{
  "patient": "张",
  "created_start": "2025-04-01",
  "created_end": "2025-04-17",
  "page": 1,
  "rows": 10
}

返回示例
成功返回
{
    "ErrCode": 0,
    "ErrMsg": "",
    "IsSuccess": true,
    "Data": {
        "filename": "（处方订单）20250917230433412.xlsx",
        "filepath": "http://127.0.0.1:11825///00//export/bus/2025-09//（处方订单）20250917230433412.xlsx"
    }
}

错误返回
{
  "errcode": 400501,
  "data": {},
  "errmsg": "查询失败",
  "issuccess": false
}

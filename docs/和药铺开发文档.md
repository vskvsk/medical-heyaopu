# 接口文档合集

## 00. access_token 接口必读

### 常见配置

#### 请求头部 (http header)

| 参数           | 值                                      | 说明                 |
|----------------|-----------------------------------------|----------------------|
| access_token   | 通过登录接口获取                        | 验证对接平台信息     |
| Content-Type   | application/json;charset=utf-8          | post/put 请求时最好是 json 格式，get 请求不需要 |

**例子：**

```
access_token: 7b26554427a8b9f95ee30a41d141a45d
Content-Type: application/json;charset=utf-8
```

### token 的获取方法

- 通过登录接口获取 access_token，即请求头里的 token 参数。
- 失效时间：7200 秒自动失效。

### 接口地址

| 说明             | 值                           |
|------------------|------------------------------|
| 和药辅测试环境   | http://47.98.242.169:8010    |
| 和药辅正式环境   | https://doc.suhzy.com/a-api/ |

### 使用账号

| 说明             | AppID         | AppSecret     |
|------------------|---------------|---------------|
| 和药辅测试环境   |               |               |
| 和药辅正式环境   | 未提供具体值   | 未提供具体值   |

注意：登录成功后，可以在请求参数中携带身份验证信息（即在请求参数中传 access_token）。

### 全局参数

API 统一返回格式

- 正确结果：

```json
{
  "errcode": 0,
  "errmsg": "",
  "data": []
}
```

- 错误结果：

```json
{
  "errcode": 10000,
  "errmsg": ""
}
```

### 全局输入参数说明

| 字段名        | 是否必填 | 描述                     |
|---------------|----------|--------------------------|
| access_token  | true     | 必须要有（登录接口 get） |

### 全局返回参数说明

| 字段名   | 数据类型 | 描述                                                                 |
|----------|----------|----------------------------------------------------------------------|
| errcode  | int      | 返回代码，0 表示返回结果正常，其它值表示出错                         |
| errmsg   | string   | 错误消息（当 errcode 不为 0 时）                                     |
| data     | json     | 实际数据                                                             |
| total    | int      | 数据总条数（非当前结果集条数，为实际查询条件的总数值）               |
| rows     | int      | 每页的数量（data 为 list 时会出现的字段）                            |
| page     | int      | 页码（data 为 list 时会出现的字段）                                  |

### errcode 参数说明

| 值   | 描述                                          |
|------|-----------------------------------------------|
| 0    | 接口访问成功                                  |
| 400  | 当前 [access_token] 已过期，请重新获取        |
| 401  | 链接失败，请确认 Headers [access_token] 的值  |
| 404  | 链接失败，Headers [access_token] 解析出现异常 |
| 501  | 其他错误，具体看 ErrMsg 内容                  |

### 简要描述

- 使用管理后台的用户账号进行账号登录，获取用户 access_token

### 请求 URL

### 请求方式

## 02. 获取处方列表接口

### 简要描述

- 获取处方列表数据（支持多条件查询）

### 请求 URL

- `/api/prescribe/photo`

### 请求方式

- POST, body

### 请求头

- 参考接口必读中的请求头设置

| 字段名         | 字段类型 | 是否必填 | 描述                                                                 |

| cellphone      | string   |          | 患者电话                                                             |

| created_end    | string   |          | 开单结束时间                                                         |
| paymentd_start | string   |          | 付款起始时间                                                         |
| paymentd_end   | string   |          | 付款截止时间                                                         |
| page           | int      | 是       | 页码                                                                 |
| rows           | int      | 是       | 分页行数                                                             |

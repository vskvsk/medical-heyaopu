# 获取药剂类型列表接口

## 简要描述

获取药剂类型列表数据

## 请求信息

- **请求URL**: `/htai/bd/drug_types`
- **请求方式**: `GET`
- **请求头**: 参考接口必读中的请求头设置
- **请求参数**: 无需添加请求参数，默认返回所有药剂类型

## 特殊说明

### 1. 药材等级说明

```json
{
    "drug_level": "默认药材等级主键",
    "drug_level_name": "默认药材等级", 
    "drug_level_combox": [
        {"value": "DIC2022010001", "code": "￥PT", "text": "普通"}
    ]
}
```

- `drug_level_combox` 为当前药剂类型下可选择的药材等级
- 药材等级选项影响开单时的药材价格信息  
- 不同药剂类型拥有不同的药材等级配置

### 2. 用药方式说明

```json
{
    "drug_mmode": "默认用药方式主键",
    "drug_mmode_combox": [
        {"value": "DIC2022030020", "code": "01", "text": "内服"}
    ]
}
```

- 当 `drug_mmode_combox` 为空数组时，开方页面不显示"用药方式"选项
- 直接开方时默认选中第一个选项 (`drug_mmode_combox[0]`)
- 操作位置应放在药材计量下方
- 处方明细页显示字段为 `drug_mmode`，为空时不显示

### 3. 包装方式说明

```json
{
    "dt_packmethod": "默认包装方式主键",
    "dt_packmethod_combox": [
        {"value": "DIC2020070002", "code": "brandpack", "text": "品牌包装"}
    ]
}
```

- 当 `dt_packmethod_combox` 为空数组时，开方页面不显示"包装方式"选项
- 直接开方时默认选中第一个选项 (`dt_packmethod_combox[0]`)
- 操作位置应放在药材计量下方
- 处方明细页显示字段为 `dt_packmethod`，为空时不显示

# 和药铺接口集成 - 启动和测试指南

## 快速启动

### 1. 安装依赖
```bash
npm install
# 或者
yarn install
```

### 2. 启动开发服务器
```bash
npm run serve:dev
```

系统将在 `http://localhost:8000` 启动，并自动配置代理到和药铺测试环境。

## 常见问题排除

### 1. CORS跨域错误
**问题**：`Access to XMLHttpRequest has been blocked by CORS policy`

**解决方案**：
- 确保开发服务器正在运行（`npm run serve:dev`）
- 检查代理配置是否正确
- 重启开发服务器

### 2. 登录失败
**问题**：登录时提示用户名或密码错误

**解决方案**：
- 检查网络连接
- 确认使用正确的测试账号
- 查看浏览器开发者工具的网络请求

### 3. 接口返回401错误
**问题**：接口调用返回认证失败

**解决方案**：
- 检查access_token是否正确存储
- 重新登录获取新的token
- 检查请求头是否包含正确的认证信息

### 4. 数据格式错误
**问题**：页面显示异常或数据缺失

**解决方案**：
- 检查API接口的数据转换逻辑
- 查看浏览器控制台的错误信息
- 对比和药铺接口文档确认数据格式

## 调试技巧

### 1. 查看网络请求
打开浏览器开发者工具 → Network 标签页，查看：
- 请求URL是否正确
- 请求参数格式是否符合和药铺接口要求
- 响应数据格式是否正确

### 2. 查看控制台日志
打开浏览器开发者工具 → Console 标签页，查看：
- API调用的详细日志
- 数据转换过程的日志
- 错误信息和堆栈跟踪

### 3. 检查本地存储
打开浏览器开发者工具 → Application → Local Storage，检查：
- `Access-Token` 是否正确存储
- Token格式是否为 `Bearer xxx`

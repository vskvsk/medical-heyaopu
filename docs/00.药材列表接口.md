
简要描述
- 获取药材列表数据

请求URL
- /api/bd/drug_materials

请求方式
- POST，body

请求头
- 参考接口必读中的请求头设置

请求参数
字段名
字段类型
查询权重
描述
pk_druglevel
string
必填
药品等级PK(必填项)
pk_prescribe
string
1
处方单主键(复制处方明细时使用)
pk_prescript
string
2
处方模板主键(参照处方模板时使用)
materials
list[]
3
指定药材查询(格式见示例)
iaccessories
int
4
iaccessories=1时获取辅料时使用
contain
string
5
模糊查询，支持首字母、中文

请求示例
获取药材基本信息（不含价格信息）
//药材登记PK为空时，默认加载药材档案列表，将不会返回药材价格信息！
{
    "pk_druglevel": "" ,
    "page": 1,
    "rows": 10
}

模糊查询示例
{
    "pk_druglevel": "DIC2022010001",//普通
    "contain": "大枣"
}

处方模板查询示例
{
    "pk_druglevel": "DIC2022010001",
    "pk_prescript": "PT001"
}

辅料查询示例
{
    "pk_druglevel": "DIC2022010001",
    "iaccessories": 1
}

指定药材查询示例
{
    "pk_druglevel": "DIC2022010001",
    "materials": [
        {
            "pk_materials": "YP000101",
            "drug_unit": "DIC2019020026"
        },
        {
            "pk_materials": "YP001203", 
            "drug_unit": "DIC2019020026"
        }
    ]
}

请求示例
{
    "pk_druglevel": "DIC2022010001",
    "pk_prescribe":"Pk2022010001",
    "materials": [
        {

        }
    ]
}


简要描述
- 获取字典列表数据

请求URL
- /htai/bd/dictionaries

请求方式
- GET

请求头
- 参考接口必读中的请求头设置

请求参数
- 无需添加请求参数，默认返回所有字典内容

返回示例
成功返回
{
    "errcode": 0,
    "errmsg": "",
    "data": [
        {
            "value": "字典主键",
            "text": "字典名称",
            "code": "字典编码",
            "childrens": [
                {
                    "value": "二级字典主键",
                    "text": "二级字典名称",
                    "code": "二级字典编码"
                }
            ]
        }
    ]
}

错误返回
{
    "errcode": 400401,
    "data": [],
    "errmsg": "你的帐号已在其他地方登录，本地已经下线",
    "issuccess": false
}

字段说明
字段名
字段类型
描述
value
string
字典主键，提交时使用
text
string
字典名称
code
string
字典编码
childrens
list[]
二级字典内容

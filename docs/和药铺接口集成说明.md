# 和药铺接口集成说明

## 概述

本系统已成功集成和药铺的四个核心接口，实现了完整的处方管理流程。

## 集成的接口

### 1. 后台用户登录接口
- **接口地址**: `/htai/token/login`
- **请求方式**: GET
- **对应页面**: `src/views/user/Login.vue`
- **功能**: 使用手机号和密码登录，获取access_token

### 2. 获取处方列表接口
- **接口地址**: `/api/prescribe/photo`
- **请求方式**: POST
- **对应页面**: `src/views/verify/List.vue`
- **功能**: 获取处方列表，支持多条件查询

### 3. 获取处方明细接口
- **接口地址**: `/api/prescribe/load`
- **请求方式**: POST
- **对应页面**: `src/views/verify/Detail/index.vue`
- **功能**: 获取指定处方的详细信息

### 4. 处方编辑接口
- **接口地址**: `/api/prescribe/update`
- **请求方式**: POST
- **对应页面**: `src/views/verify/Detail/index.vue`
- **功能**: 更新已有处方数据

## 主要修改内容

### API接口层 (`src/api/annotation.js`)
1. 更新了接口地址映射
2. 适配了和药铺的请求参数格式
3. 转换了返回数据格式以兼容现有前端组件
4. 添加了access_token认证头处理

### 请求工具 (`src/utils/request.js`)
1. 修改请求拦截器，支持access_token认证方式
2. 更新响应拦截器，处理和药铺接口的错误码格式
3. 兼容原有Authorization头以支持混合接口调用

### 登录页面 (`src/views/user/Login.vue`)
1. 适配新的登录接口返回格式
2. 正确处理accessToken的存储

### 环境配置
1. 创建了和药铺专用环境配置 `.env.heyaopu`
2. 更新开发环境配置指向和药铺测试环境

## 环境配置

### 和药铺测试环境
- 地址: `http://47.98.242.169:8010`
- 配置文件: `.env.dev` (开发环境)

### 和药铺正式环境
- 地址: `https://doc.suhzy.com/a-api/`
- 配置文件: `.env.heyaopu` (生产环境)

## 数据格式转换

系统自动处理以下数据格式转换：

### 登录接口
- 输入: `{ mobile, password }`
- 转换为: `{ code, pwd }`
- 返回: 统一格式的token信息

### 处方列表接口
- 输入: 标准分页查询参数
- 转换为: 和药铺格式的查询参数
- 返回: 统一格式的列表数据

### 处方详情接口
- 输入: 处方ID
- 转换为: `{ pk_prescribe }`
- 返回: 统一格式的详情数据

### 处方编辑接口
- 输入: 标准处方数据格式
- 转换为: 和药铺完整的处方更新格式
- 返回: 统一格式的操作结果

## 使用说明

1. **启动开发环境**:
   ```bash
   npm run serve:dev
   ```

2. **登录系统**:
   - 使用和药铺提供的测试账号登录
   - 系统会自动获取并存储access_token

3. **查看处方列表**:
   - 访问处方列表页面
   - 支持按医生姓名、处方编号等条件搜索

4. **查看处方详情**:
   - 点击列表中的"查看详情"按钮
   - 系统会自动加载处方的完整信息

5. **编辑处方**:
   - 在详情页面进行编辑
   - 保存时会调用和药铺的更新接口

## 注意事项

1. **认证方式**: 和药铺接口使用access_token作为认证头，而非标准的Authorization Bearer
2. **错误处理**: 和药铺接口使用errcode/errmsg格式返回错误信息
3. **数据格式**: 部分字段名称和数据结构与原系统不同，已做自动转换
4. **接口超时**: 建议设置合适的请求超时时间以应对网络延迟

## 测试建议

1. 首先测试登录功能，确保能正确获取access_token
2. 测试处方列表查询，验证数据格式转换是否正确
3. 测试处方详情查看，确认所有字段都能正确显示
4. 测试处方编辑功能，验证数据能正确提交到和药铺系统

## 故障排除

如果遇到接口调用问题，请检查：
1. 网络连接是否正常
2. access_token是否有效
3. 请求参数格式是否正确
4. 和药铺服务是否正常运行
